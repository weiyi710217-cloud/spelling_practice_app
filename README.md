# 互動式單字練習 App (Python + HTML)

這是一個專為小學生設計的 **互動式單字克漏字填空練習 App**，介面完全比照指定畫面設計，並已預先內建 `Sunshine Spelling Bee Intermediate Word List (#81 ~ #160)` 共 80 個單字與**小學三年級程度**的英文練習例句。

## ✨ 核心功能
1. **完整復刻練習面板**：
   - 顯示 `得分：0 / 30`、`錯題資料庫：X 題`、`本輪進度：X / 總題數`
   - **1. 檢查答案**：即時批改並標示紅/綠底色與正確答案解析
   - **2. 抽30題 (未練優先)**：自動優先抽取本輪尚未練習過的單字
   - **3. 只練錯題庫**：只要答錯就會永久存入錯題庫，直到在錯題模式中答對才會消除
   - **🔊 雙語音朗讀**：點擊每題左側綠色喇叭按鈕，自動朗讀「單字 + 完整英文例句」
   - **字數提示**：每個空格自動顯示 `(N字)` 提示
2. **支援上傳多張單字圖片擴充題庫**：
   - 點擊「📤 上傳多張單字圖片」，可一次選取多張課本或單字表照片
   - 系統會透過 AI 自動辨識圖片內所有單字，並用**小學三年級的能力**生成生活化英文挖空例句加入題庫
3. **清除題庫 / 還原題庫 / JSON 匯出入**：
   - 點擊「⚠️ 清除題庫」可一鍵清空所有題目重新開始
   - 點擊「🔄 還原預設80題」可隨時載回附圖的 80 個單字

## 🚀 部署到 GitHub 的兩種方式

### 方式一：直接部署在 GitHub Pages（免伺服器、最簡單）
1. 將本專案檔案上傳至您的 GitHub Repository。
2. 進入 GitHub Repo 的 **Settings** -> **Pages** -> **Build and deployment** 選擇 `Deploy from a branch` (`main` branch)。
3. 打開產生的 GitHub Pages 網址即可直接使用！若要上傳新圖片，只需在頁面上方填入您的 Gemini API Key 即可在瀏覽器端直接辨識多張單字圖片。

### 方式二：使用 Python Flask 後端執行
```bash
pip install -r requirements.txt
export GEMINI_API_KEY="您的_API_KEY"
python app.py
```
打開瀏覽器前往 `http://127.0.0.1:5000` 即可使用。
